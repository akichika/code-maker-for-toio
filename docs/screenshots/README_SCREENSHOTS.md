# Screenshots

このフォルダにスクリーンショットを追加してください。

推奨ファイル名:
- `overview.png`        — アプリ全体のスクリーンショット
- `blockly_workspace.png` — Blocklyワークスペース (ブロック組み立て画面)
- `simulator.png`       — シミュレーター画面
- `card_scanner.png`    — カードスキャナー (カード認識画面)
- `code_view.png`       — コード表示タブ (JS / Python)
- `ai_tab.png`          — AI コード生成タブ
- `themes.png`          — ライト / ダーク / ハイコントラスト テーマ比較
- `multi_lang.png`      — 多言語切替 (JA / EN / ZH)

## 推奨スクリーンショット手順

1. `python -m http.server 3333` でローカルサーバーを起動
2. ブラウザで `http://localhost:3333` を開く
3. 各機能の画面を全画面キャプチャ (例: Win + Shift + S)
4. このフォルダに保存して README.md の `<!-- SCREENSHOT: ... -->` コメントのパスと合わせる
